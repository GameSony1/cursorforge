# CursorForge

Приложение для кастомизации курсора Windows в игровом стиле: библиотека курсоров, живой предпросмотр, настройка цвета/размера/толщины/прозрачности и реальное применение системного курсора. В будущем — модуль игрового лаунчера.

Статус: ранняя разработка (дизайн и базовый функционал библиотеки/применения курсоров).

## Структура

- `apps/desktop` — Electron + React (главное приложение)
- `apps/server` — сервер каталога скинов курсоров
- `packages/shared` — общие типы и векторные формы курсоров

## Запуск

```bash
npm install
npm run dev
```

Поднимет сервер скинов (`http://localhost:4000`) и десктоп-приложение с горячей перезагрузкой.

## Сборка

```bash
npm run build
```
